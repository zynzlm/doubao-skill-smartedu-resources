# WorkBuddy / CodeBuddy 安装说明

同目录的 `SKILL.md` 是 `smartedu-resources` 技能的 WorkBuddy 适配版。脚本和接口文档仍然用上一级的 `smartedu-resources/scripts`、`smartedu-resources/references`，不要重复拷贝第二份。

## 安装（在 WorkBuddy 里 3 步）

1. 克隆仓库：

```bash
git clone https://github.com/zynzlm/doubao-skill-smartedu-resources.git
```

2. 把技能目录拷到 `.codebuddy/skills/`：

```bash
# 项目级（只当前项目可用）
mkdir -p .codebuddy/skills
cp -r doubao-skill-smartedu-resources/smartedu-resources .codebuddy/skills/smartedu-resources

# 或用户级（所有项目可用）
mkdir -p ~/.codebuddy/skills
cp -r doubao-skill-smartedu-resources/smartedu-resources ~/.codebuddy/skills/smartedu-resources
```

3. 用适配版覆盖技能主文件：

```bash
cp doubao-skill-smartedu-resources/workbuddy/SKILL.md .codebuddy/skills/smartedu-resources/SKILL.md
```

然后重开会话（或跑 `/reload-plugins`），在输入框敲 `/smartedu-resources` 可以手动调用，直接说“下人教版八年级上册物理第五章的全部资料”这类需求也会自动匹配。

## 依赖

```bash
pip install requests pillow pymupdf python-pptx python-docx
```

| 依赖 | 用途 |
|---|---|
| `pillow` | 页面图合成 PDF |
| `pymupdf` | 课件 PDF → PPTX、页图预览 |
| `python-pptx` | 写 PPTX |
| `python-docx` | 写 docx |
| `requests` | 可选，脚本本体用标准库 `urllib` |

## 与豆包版 SKILL.md 的差别

只有两处，功能性一致：

1. frontmatter 多了 `allowed-tools: Read, Write, Bash, Glob`，否则 WorkBuddy 默认不给跑脚本的权限。
2. 第四节登录改成通用说法：不再调用豆包专用的 `computer_use_tool(plane="bu")` 和 `interaction_request_action`，改为“打开登录页 → 明确告诉用户要做什么 → 停下等待 → 用户完成后重新确认”。视频与资源库才需要登录，其余脚本路径全部是公开接口。

如果你的 WorkBuddy 版本对 frontmatter 字段管得更严（只允许 `name` + `description`），把 `allowed-tools` 那一行删掉即可，脚本依然能在 Bash 权限下跑。
